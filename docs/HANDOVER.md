# 小秘書交接說明（給不會寫程式的接手者）

這份文件假設你完全不會寫程式。照著做就能把資料拿走，或找人接手。

## 這是什麼
一個 LINE 官方帳號「小秘書」：傳一句話給它，它會幫忙記待辦、設提醒、存筆記，到時間主動通知。資料存在一個叫 **Supabase** 的線上資料庫，程式跑在 **Vercel**。

## 你需要知道的三個地方
| 名字 | 用途 | 誰有帳號 |
|---|---|---|
| LINE Official Account Manager | 管理官方帳號本身 | 原維護者（請向他要管理權限） |
| Supabase | 資料庫，所有資料都在這裡 | 原維護者 |
| Vercel | 讓程式在網路上運作 | 原維護者 |

> 交接最重要的一件事：**請原維護者把這三個帳號的管理權限分給你（或你信任的人）**。沒有權限，資料還在，但沒有人能修改或下載。

## 一、把資料帶走（最簡單，不用任何帳號）
1. 打開小秘書的設定頁：網址是 `https://（小秘書的網址）/setup.html`，輸入密碼（DASHBOARD_TOKEN，向維護者拿）。
2. 捲到最下面「備份與交接」。
3. 按「**下載離線閱讀檔**」，會得到一個 `.html` 檔。**雙擊它**，用 Chrome／Safari／Edge 開就能看：可以搜尋，可以篩選待辦、提醒、筆記。不需要網路。
4. 想用 Excel 看就按「下載 Excel 表格（CSV）」。
5. 「下載完整資料（JSON）」是給工程師用的完整備份，請一起收好。

建議：每個月下載一次，放在雲端硬碟或隨身碟。

## 二、日常怎麼用
- 在 LINE 傳「明天下午三點開會」就會記成提醒，到時間會通知。
- 傳「今天」看今天的事，「待辦」看全部未完成。
- 聊天視窗下方有三個分頁的按鈕選單，點就能用。
- 網頁後台（待辦頁面）也能看和改，網址同上，但不加 `/setup.html`，要帶密碼。

## 三、如果小秘書不回話了
1. 先確認 LINE 官方帳號有沒有被停用（Official Account Manager）。
2. 到 Vercel 看專案是不是被暫停或額度用完。
3. 到 Supabase 看專案是不是因為太久沒用被暫停（免費方案超過一週沒動靜會暫停，按「Restore」就好）。
4. 還是不行，找原維護者或任何會用 GitHub 的人，請他看 `README.md`。

## 四、要停用或搬家
- **停用**：在 LINE Official Account Manager 關閉訊息功能即可，資料不會消失。
- **搬家**：先做「一、把資料帶走」，再把 JSON 檔交給工程師，他可以匯入新的資料庫。
- **完全刪除**：到 Supabase 刪掉專案，到 Vercel 刪掉專案。**刪除前一定要先下載備份，刪了就找不回來。**

## 五、有哪些資料、不包含什麼
- 包含：所有待辦、提醒、筆記、專案更新、週報，以及服事表資料（如果有用）。
- 不包含：傳給小秘書的圖片檔案（在 Supabase 的 `note-images` 資料夾，要到 Supabase 後台另外下載）、各種金鑰與密碼（這些在 Vercel 的環境變數，請向原維護者要）。
